Destinations receive UDP OSC from the gateway. The matrix chooses which source feeds which destination; empty cells default to on (all → all).

Gateway listens here for inbound UDP (controller feedback + incoming monitor).

Rows are sources, columns are destinations. Unchecked = do not send. Incoming OSC senders appear as extra rows and are passed through by default.

Default mode for every signal on a newly added source. Existing sources keep their own settings.
